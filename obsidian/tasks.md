## Наступний крок

Гайди (обидва репо) готові до Фаз 14-16 (фронтенд) і 9-10 (бекенд), але
**жоден рядок коду з них ще не набрано руками** — саме з цього
продовжувати. Рекомендований порядок (є залежності між фазами):

1. **Бекенд Фаза 9 першою** — зараз автопарк відкритий без авторизації
   (реальна діра, не косметика). Після цього Фаза 10 (nested
   specs/trailer write).
2. **Фронтенд Фаза 14** — виправляє корінний баг маршрутизації (`/`
   веде на `/driver` для всіх, минаючи лендінг/логін-модалку) — без
   цього Фази 15/16 не мають сенсу тестувати (нема способу зайти під
   потрібною роллю через UI).
3. **Фронтенд Фаза 15** (QR-сканер водія) і **Фаза 16** (автопарк
   логіста) — незалежні одна від одної, можна в будь-якому порядку
   після Фази 14.

```bash
git checkout main
git pull origin main
git checkout -b feature/faza-14-role-routing
```

`CODING_GUIDE.md`, було "Крок 18").

## Відкриті питання

- `package-lock.json` — досі дрібні локальні розходження, не мої,
  не займав жодного разу.
- Інший процес комітить/мержить у `main` незалежно від цієї сесії —
  перед плануванням нової гілки звіряй `git log`.
